# 微信小程序 - 设计文档（草案）

> **状态：待续讨论** — 架构方向已确认，细节待后续展开

## 1. 决策记录

| 决策点 | 结论 |
|--------|------|
| 技术方案 | **Taro**（React + TypeScript），复用现有代码 |
| 覆盖范围 | **全平台**（家长端 + 孩子端） |
| 登录方式 | 小程序端**仅微信登录**（`wx.login` → openid） |
| 家长/孩子模式 | **家长登录后选择模式**（管理模式 / 学习模式切换） |
| 账号体系 | 小程序**独立注册**，不和 Web 端账号互通 |
| 项目结构 | **Monorepo**：现有 Next.js 作为 API 后端，新增 `/miniprogram` 放 Taro 项目 |

## 2. 整体架构

```
┌─────────────────┐     HTTPS/JWT      ┌──────────────────────┐
│  微信小程序       │ ◄─────────────────► │  Next.js API 后端     │
│  (Taro + React)  │                    │  (现有项目，保留)      │
│                  │                    │                      │
│  - 孩子学习模式   │                    │  - /api/auth/*        │
│  - 家长管理模式   │                    │  - /api/children/*    │
│  - 打卡/积分/宠物 │                    │  - /api/learning/*    │
│                  │                    │  - /api/checkin/*     │
└─────────────────┘                    │  - /api/wechat/* (新增)│
                                       │  - Prisma + SQLite     │
┌─────────────────┐                    └──────────────────────┘
│  Web 端 (保留)   │── 用户名密码登录 ──►
│  家长管理        │
└─────────────────┘
```

- **Web 端**：保留，用户名密码登录，家长管理用
- **小程序端**：微信登录，独立账号体系，家长和孩子都在同一设备上操作
- **后端共用**：同一套 API，新增微信登录接口，已有 API 加 JWT 认证

```
kidstudy/
├── src/                    # 现有 Next.js 项目（保留作为 API 后端 + Web 前端）
├── miniprogram/            # 新增 Taro 项目

│   │   ├── hooks/          # 复用/适配现有 hooks

│   └── ...

│   ├── types/              # 从 src/types 提取
│   └── constants/          # 积分规则、科目配置等

```
